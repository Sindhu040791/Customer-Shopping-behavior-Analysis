🛍️ Customer Shopping Behavior Analysis

📌 Project Overview

This project focuses on analysing customer shopping behaviour to understand purchasing patterns, customer preferences, sales performance, and revenue trends.

🛠️ Tools & Technologies Used

🐍 Python (Pandas): Data cleaning, data preparation, and analysis using VS Code.

🗄️ PostgreSQL: Data querying and analysis.

📊 Power BI: Interactive dashboard development and data visualization.

🔄 Project Workflow

1️⃣ Data Cleaning & Preparation

Imported and inspected the customer shopping dataset using Python.

Performed data cleaning and preparation using Pandas.

2️⃣ SQL Analysis

Used PostgreSQL to perform data queries and analyse customer shopping patterns.

Explored sales, revenue, and customer-related information.

3️⃣ Dashboard Development

Developed an interactive Power BI dashboard.

Used charts, KPI cards, and slicers to visualize customer behaviour and sales performance.

📈 Key Insights

👥 Customer Subscription: 73% of customers are non-subscribers, while 27% have subscriptions.

👕 Revenue by Category: Clothing generates the highest revenue.

🛒 Sales Performance: Clothing leads with 1,737 sales.

👩‍💻 Age Group Analysis: Young adults contribute the highest revenue and sales.

💰 Average Purchase Amount: $59.76.

💡 Recommendations

🎯 Encourage more customers to subscribe through special offers.

🛍️ Focus on high-performing product categories.

📢 Introduce targeted promotions for different age groups.

⭐ Improve customer satisfaction through review analysis.

🎯 Project Outcome

This project helped me strengthen my practical skills in data cleaning, SQL querying, data analysis, and dashboard development using Python, PostgreSQL, and Power BI.
